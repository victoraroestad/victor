# Personvernerklæring for PengeFlyt DEV

Oppdatert 23. november 2026.

PengeFlyt DEV er en privat og ikke-kommersiell applikasjon for familieøkonomi. Applikasjonen er laget for bruk innen én husholdning og tilbys ikke som en offentlig tjeneste.

## Hvilke opplysninger behandles?

Når kontoeieren gir nødvendig samtykke, kan PengeFlyt lese kontoinformasjon, bokførte transaksjoner og saldo fra særskilt autoriserte bankkontoer gjennom Enable Banking. Husholdningen kan også registrere egne budsjettopplysninger og økonomiske notater.

Opplysningene brukes til økonomisk oversikt, kategorisering, budsjettering, historikk og avstemming. PengeFlyt kan ikke igangsette betalinger eller pengeoverføringer gjennom bankintegrasjonen.

## Lagring, tilgang og tredjepartstjenester

Opplysninger som importeres til PengeFlyt, lagres i en privat Azure-installasjon med innloggingskontroll. De to voksne i husholdningen har etter avtale tilgang til fellesøkonomien. Privat skjerming mellom voksne er ikke aktivert i den nåværende installasjonen.

Enable Banking og den aktuelle banken behandler opplysninger i forbindelse med bankautorisasjonen og levering av kontoinformasjon. Microsoft Azure brukes til drift og lagring. Disse tjenestene har egne vilkår og personvernerklæringer.

PengeFlyt selger ikke bankopplysninger og bruker dem ikke til reklame.

## Samtykke, frakobling og tidligere data

Kontoeieren kan trekke tilbake bankens samtykke gjennom banken eller Enable Banking. Bankintegrasjonen kan også kobles fra i PengeFlyt. Frakobling stanser videre innhenting via den tilkoblingen, men sletter ikke automatisk allerede importerte transaksjoner, observasjoner, historikk eller sikkerhetskopier. Sletting og eventuell opprydding må håndteres separat.
